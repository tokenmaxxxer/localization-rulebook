# Locale-fitness checklist (체크리스트 축)

`localization-verdict-axis`가 담당하는 두 축 중 체크리스트 축의 정적
절차. 대상 표면이 코드·문자열 리소스가 아니면 통째로 N/A(해당 없음 사유
명시) 처리한다.

- [ ] **문자열 외부화**: 사용자 대면 문자열이 소스 코드에 하드코딩되지
  않고 리소스 파일(예: .po/.json/.strings/.resx)로 분리되어 있는가.
- [ ] **인코딩**: 리소스 파일이 UTF-8(또는 대상 로케일이 요구하는
  인코딩)로 저장되어 로케일 문자 집합을 손실 없이 표현하는가.
- [ ] **plural 규칙**: 대상 로케일의 복수형 규칙(CLDR plural category —
  one/few/many/other 등, 언어별로 다름)에 맞는 분기가 존재하는가. 영어
  단수/복수 2분기만 있고 다른 로케일의 규칙을 반영하지 않으면 미충족.
- [ ] **키 완전성**: 기준 로케일(원문)에 존재하는 모든 문자열 키가 대상
  로케일 리소스에도 존재하는가(값이 비어 있거나 누락된 키가 없는가).

## N/A 규칙

대상 표면에 코드·문자열 리소스가 아예 없는 경우(예: 순수 설계 문서,
API 스펙)에만 이 축 전체를 N/A로 표기한다. N/A로 표기할 때는 사유를
반드시 병기한다 — 예: `checklist=N/A(no string resources, design-only doc)`.
"검토 안 함"의 의미로 N/A를 쓰지 않는다.
